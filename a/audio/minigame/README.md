# 초선무쌍 · 클리어 후 미니게임 BPM 음악

정식 요구사항: [미션 종료 후 일러스트·미니게임 기획](../../../docs/POST_MISSION_ILLUSTRATION_MINIGAME.md).

추후 이 위치에 다음 **MP3 실파일**을 넣는다.

- `bpm_90.mp3` ← `USE_타격음악_90BPM_합본.mp3`
- `bpm_120.mp3` ← `USE_타격음악_120BPM_합본.mp3`
- `bpm_150.mp3` ← `USE_타격음악_150BPM_합본.mp3`

각 120.033초 · 44.1kHz · stereo · 약 160kbps. 제공한 음원의 비트·리듬 분류용 이름이며, 사용 조건은 아직 미결정. 기존 게임 음악과 합치거나 덮어쓰지 않는다.

**현재 MP3는 이 저장소에 아직 올라가지 않았다.** 업로드가 완료되면 `manifest.json`의 SHA256을 확인하고 `repository_uploaded` 상태를 갱신한다. 업로드 전 미니게임 재생을 구현한 것처럼 기록하거나 보고하지 않는다.
