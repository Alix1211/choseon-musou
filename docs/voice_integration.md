# 초선 음성 연동 안내

녹음 음원 107개는 `a/voice/` 아래 다음 디렉터리로 배치합니다.

* `skills/` (28개)
* `battle/` (8개)
* `stage/` (44개)
* `map/` (21개)
* `event/` (6개)

정정본은 ChatGPT 대화에서 전달한 `Choseon_Voice_107_CORRECTED.zip`입니다.
이 ZIP의 각 폴더를 `a/voice/` 밑에 그대로 풀어넣으면 Gradle의 `syncGameAssets`가 자동으로 APK에 포함합니다.

게임 코드 `index.html`은 `CM_AUDIO.playVoice`로 음성을 불러옵니다.
기술명은 실제 기술 발동 시, 전투 대사는 간헐적으로, 스테이지·칸 대사는 초선 대화 표시 시 사용합니다.
기존 BGM 및 효과음은 그대로 둡니다. 효과음 설정을 끄면 음성도 꺼집니다.
`a/voice` 자산을 업로드하지 않은 빌드는 음성이 조용히 생략되며 게임 진행에는 영향을 주지 않습니다.

속도 v0.6: 일반 약공격 0.45초 / 강공격 0.62초. 특수 연속기의 별도 지속시간은 유지합니다.

임시 테스트 서명 키를 사용하며 정식 출시 키는 별도 관리해야 합니다.

## 2026-10-30 음성 우선순위 확정

- **1 최하위: 모든 기술명** (검·채찍·부채 스킬 및 무쌍난무). 다른 음성이 재생 중이거나 불러오는 중이면 기술명은 재생하지 않는다. 대기열에 넣지 않으며 나중에 밀린 기술명이 나오지 않는다.
- **2 중간: 일반 전투 대사**. 기술명 재생 도중 시작하면 기술명을 즉시 정지시킨다. 같은 전투 대사끼리는 중복하지 않고 기존 3.5초 간격 제한을 유지한다.
- **3 최상위: 스토리·맵·이벤트 대사**. 모든 기술명과 전투 대사를 즉시 중지하고 재생한다.
- 기술명 재생 요청이 들어왔다가 비동기 음성 로딩 중 상위 음성이 재생되더라도, 이전 기술명이 뒤늦게 재생되지 않도록 토큰 및 로딩 중 상태로 제어한다.
- 음성은 대사/기술명 독립 재생이며 기존 배경음과 효과음 설정은 유지한다.
