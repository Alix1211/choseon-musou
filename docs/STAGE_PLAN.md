# 40개 스테이지 규칙 배치안 (케인 승인: 2026-10-29, "표 그대로 진행")

목적: 지금은 4~40판이 "부장을 잡고 문을 열어 다음 칸으로 → 마지막에 장수 구출"만 반복돼 지루하다.
진삼국무쌍 시리즈의 전투 구성(화계·수공·감시탑 점령·성문·샛길 우회·피난민 호위·미로·복병·전령 차단)을 참고해 판마다 규칙을 달리한다.
이미 있는 규칙: 1판 NPC 거점병장(처치하면 문 열림), 3판 독 연기.

- **스테이지 = 나라**: 1~10 위, 11~20 오, 21~30 촉, 31~40 군웅(세 나라 병사 섞임).
- 담당: **GPT** = 가벼움(지금 있는 문·스위치 장치 재사용), **Claude** = 중간·큼(새 시스템·시간제한·호위·화계·수공·미인계), 그리고 소리·APK.
- 이 표는 **방향**이다. 세부(몇 개, 어디에, 제한 시간)는 구현하며 조정하되, 규칙의 종류를 바꾸려면 케인에게 먼저 묻는다.
- 케인 대사·원고는 절대 고치지 않는다. 새 안내 문구(목표 문장 등)는 짧게, 코미디 톤은 케인의 기존 문장에서 벗어나지 않게.

## 조사 요약 (진삼국무쌍 시리즈의 규칙 종류)
- 화계: 황개 불배 돌진, 제갈량 동남풍 기원까지 버티기(적벽). 우초 보급창 소각으로 적 사기 하락(관도).
- 수공: 수문을 지키는 장수를 쓰러뜨리면 성이 침수(하비).
- 거점·성문: 감시탑 제한시간 점령, 충차가 성문을 부숨, 동탁이 다치면 여포 등장(호뢰관).
- 우회·내응: 북쪽 샛길로 보급창고, 성안 내응자가 성문 개방(사수관·관도·하비).
- 호위: 피난민·아두를 지키며 선착장까지(장판파).
- 미로·복병: 안개 낀 돌 미로(이릉), 퇴로 복병(적벽 조조 탈출).
- 전령 차단: 원군을 부르러 가는 전령을 추격해 막기(하비).
