# 2026-10-30 공격속도·콤보 연결·통합 설정 소스 수정

## 배포 상태

사용자 요청대로 소스만 수정한다. 게임 생성기·APK 빌드·배포는 하지 않았다.
`gpt-gimmicks`에 `[skip ci]` 커밋으로 저장하고 `main`·`mobile-live`·생성된 `index.html`은 변경하지 않는다.
앞서 저장한 1레벨 밸런스 수정도 그대로 유지한다.

## 공격

- 기본 약공격 동작 0.45→0.54초, 강공격 0.62→0.75초.
- 타격 완료 후 연결 허용 시점을 동작 진행률 72%→82%로 늦춰 후속 공격이 너무 빠르게 반복되지 않도록 한다.
- 콤보의 입력 순서와 기술·피해량·사거리는 유지한다.
- 콤보 입력 간격은 1.55→1.85초로 넓히고, 입력 예약 슬롯은 한 개만 유지한다.
- 예약 유효기간은 기본 1.25초, 긴 동작/둔화 중에는 현재 동작의 남은 시간+0.25초까지 확보한다.
- 돌파 0.84→1.00초, 대시 약공격 0.76→0.90초, 암석 기술 0.96→1.12초.
  회전 기술 2.24초는 유지한다. 기존 장비 공속/둔화 배율도 유지한다.
- `_new/p2combat_timing.py`가 승인 런타임 보존 패치 뒤에 적용되므로 기존 음성/채찍 수정 패치의 정확 치환을 깨지 않는다.

## 설정

- 전투의 일시정지 버튼을 톱니바퀴 설정 버튼으로 바꾼다.
- 열면 전투 로직·음악·효과음·음성을 정지한다. 입력 예약/눌림은 지우고 진행 중인 공격 종류·프레임은 보존한다.
- `전투 재개`로 돌아오면 멈췄던 공격을 이어간다. `나가기`는 기존 철수처럼 시나리오 선택으로 돌아간다.
- 효과음·배경음·음성을 각각 0~100% 슬라이더로 조절한다. 0%는 음소거이며 값은 `choseon_audio`에 저장한다.
- 음성은 효과음과 독립된 출력 Gain을 쓴다. 진행 중인 음성의 볼륨도 조절된다.
- 기존 배경음/효과음 boolean 설정은 이전 기본 음량 또는 0으로 이관한다.
- 대사 > 전투 음성 > 스킬 음성의 기존 우선순위는 유지한다.
- 설정을 열기 전 발생한 비동기 오디오 로딩이 뒤늦게 재생되지 않도록 토큰을 무효화한다.
- 진동 스위치의 상태를 저장하고 기존 `cutThump`의 `navigator.vibrate` 경로에 적용한다.
  끌 때 진행 중인 브라우저 진동도 취소한다. 새 네이티브 진동 구현은 추가하지 않았다.
- 기존 Drive 파일 연결/지금 동기화는 접힌 `저장 관리` 안에 유지한다.
- 타이틀의 설정 버튼도 같은 창을 연다. 전투 외 화면에는 `닫기`를 표시한다.
- Drive 동기화·충돌 처리 중에는 설정 창 닫기로 전투 정지를 해제할 수 없다.
- 작은 화면에서도 읽을 수 있는 기본 크기 UI와 세로 스크롤, 키보드 초점 순환을 적용한다.
