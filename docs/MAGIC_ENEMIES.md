# 초선무쌍 — 희귀 원거리 마법병 3종 (2026-10-31)

새 보스나 새 미션이 아니라 **일반 병사 한 명을 대체하는 희귀 원거리병**으로 구현한다.
총 병력 수, 40개 스테이지 규칙, 장수/거점 대장, 구출, 세이브/Drive 키는 건드리지 않는다.

| 세력 | 마법병 | 외형 색 | 사용 공격 |
| --- | --- | --- | --- |
| 위(1~10) | 파계승 | 남색 | 얼음, 뇌전 |
| 오(11~20) | 주술사 | 주홍 | 화염, 뇌전, 바람 |
| 촉(21~30) | 무녀 | 녹색 | 바람, 얼음, 뇌전 |
| 군웅(31~40) | 섞인 병사 세력에 맞춰 세 종류 모두 | 해당 세력 색 | 세력별 속성 순환 |

### 출현

- 1판은 튜토리얼이므로 미출현. 2판부터 각 판의 두 번째 칸에서 일반 병사 1명과 교체.
- 11판부터는 판의 네 번째 칸에도 1명 배치 가능(그 칸이 있을 때만).
- **한 판에 1~2명**, 일반 군락 대장과 NPC/스테이지 보스는 절대 교체하지 않음.
- 요괴 진영에는 배치하지 않고, 군웅편에서는 실제 등장한 위·오·촉 병사 세력에 맞춤.
- 2~4단계의 각국 마법을 스테이지 번호와 칸 번호에 따라 순환시켜 같은 캐릭터도 다른 주문을 사용.

### 전투

- 얼음: 청색 냉기 투사체, 맞으면 짧은 둔화.
- 뇌전: 보라색 번개 투사체 **2갈래**.
- 바람: 초록 회오리 투사체, 약한 유도.
- 화염: 붉은 화염탄.
- 기존 원거리 적의 사거리·시야·공격 준비 동작·쿨다운·벽 우회 등을 재사용하되 각 주문의 속도와 색을 구별.
- 원거리병 마법 피해에 기존 보스용 광역 장판을 중복하지 않아 난이도를 과도하게 올리지 않음.

### 이미지·동작

- `a/magic_soldiers/`의 캐릭터별 **걷기 4열×3행 / 공격 3열×3행** 투명 WebP 총 6장.
- 걷기 방향: 정면 / 오른쪽 측면 / 후면. 공격 방향: 오른쪽 측면 / 정면 / 후면.
- WebP를 APK에 포함하고 기존 APK는 `mobile-live`에서 이미지가 늦게 도착해도 게임 실행이 막히지 않도록 선택적으로 로딩한다.
- 생성된 공격 시트의 마법 궤적 일부는 셀 경계까지 닿으므로, 추후 에셋 정리 때 프레임별 누끼를 다듬을 수 있다.

### 시험

- `python3 _new/p2.py`
- `node t_magic_troops.cjs`
- 기존 `node t_combo_logic.js`, `node tools/check_ground_combo.cjs`, `node tools/check_live_cloud.cjs`
- 실제 태블릿 타격감은 사용자 플레이 확인 필요.
